# Community Garden Cooperative

A decentralized platform for managing community gardens and urban farming cooperatives on the Stacks blockchain.

## Features

- **Plot Reservation**: Gardeners can reserve plots with crop planning details
- **Community Contributions**: Members can contribute to garden maintenance costs
- **Harvest Tracking**: Coordinators can record successful harvests
- **Activity Logging**: Complete on-chain record of all garden activities

## Smart Contract Functions

### Public Functions
- `reserve-plot`: Reserve a garden plot for cultivation
- `contribute-maintenance`: Contribute to plot maintenance costs
- `record-harvest`: Record successful harvests (coordinator only)

### Read-Only Functions
- `get-plot`: Retrieve garden plot details
- `get-activity-log`: Get specific activity records
- `get-activity-count`: Get total activity count for a plot

## Usage
